# P3.31 — Exact thesis SIR analysis bridge

## Goal

Connect the existing bounded least-squares, fixed-step RK4, local sensitivity,
and residual contracts to the exact harmonic thesis SIR observer. Keep the
model-specific bridge separate from the generic declarative SIR contract.

## Scope

- Fit explicitly selected continuous transmission/removal parameters of
  `ThesisSIRParameters` through `fit_least_squares` and
  `evaluate_thesis_sir_weekly_counts`.
- Keep initial conditions, ascertainment fraction, and the discrete delay
  scenario fixed to the explicitly supplied baseline in this increment.
- Return the existing versioned fit, sensitivity, simulation, and residual
  records, plus a versioned thesis-analysis envelope with provenance.
- Bound RK4 work across fit, final evaluation, and sensitivity; preserve
  `NOT_ASSESSED` scientific validity/identifiability and
  `NOT_CALCULATED` uncertainty.
- Use only deterministic synthetic observations in tests and the example.

## Non-goals

- No optimizer, solver, uncertainty, or identifiability algorithm changes.
- No real thesis-data analysis, provider calls, generated-code execution,
  parameter defaults, or scientific-validity claims.
- No GUI changes in this engine increment; P3.32 will connect the bridge to the
  existing Qt thesis workspace after the contract is verified.

## Acceptance

1. A noise-free synthetic fixture generated by the exact thesis model can
   recover a selected transmission parameter using the existing optimizer.
2. Evaluation and sensitivity refer to the same final parameter values;
   residuals are exactly `simulated - observed` and retain week/data provenance.
3. Unsupported/discrete parameters, invalid ranges, infeasible initial-state
   bounds, non-aligned RK4 steps, and exhausted work budgets fail closed.
4. Output declares scientific validity and identifiability
   `NOT_ASSESSED`, uncertainty `NOT_CALCULATED`, and labels the fit as a
   numerical result rather than a scientific conclusion.
5. A reproducible synthetic CLI example and focused regression tests pass.
