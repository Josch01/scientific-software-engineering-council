## Cambios y decisiones

- API inmutable `OdeProblem` / `OdeSolution` y `solve_rk4` en `scripts/scientific_core.py`; Python estándar, sin instalar paquetes.
- RK4 clásico de paso fijo, rejilla uniforme con endpoint exacto, presupuesto máximo de pasos y salida JSON-safe `schema_version=1`.
- Las pruebas comparan decaimiento exponencial con `exp(-1)`, evalúan la convergencia de orden cuatro mediante step-halving y cubren contrato inválido, dimensiones, valores no finitos, presupuesto y rangos flotantes extremos.
- La decisión de no añadir SciPy evita instalar una dependencia antes de conocer si el modelo SIR exige adaptación o tratamiento de rigidez. Esa capacidad queda pendiente.
- El callback `rhs` ejecuta Python en el proceso llamador. La API no es un sandbox; no se deben ejecutar callbacks generados por agentes/no confiables dentro del proceso de la futura GUI.
